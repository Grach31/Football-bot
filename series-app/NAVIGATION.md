# Grach Films — навигация v71

## Две вкладки

- **Главная** (`#/week`): продолжить просмотр, новинки, ближайшие релизы, рекомендации. Отдельный календарь удалён. Точные даты премьер и новых серий показываются на постерах; поиск (`#/search`) открывается из верхней панели.
- **Моё** (`#/mine`): три раздела внутри одной вкладки: Сериалы (`#/mine/series`), Фильмы (`#/mine/movies`), Мой сервер (`#/mine/server`). Личные фильтры «Все / Хочу / Смотрю / Посмотрел» не создают копий данных.

## Правила данных

- Источник личных сериалов — `site/data/series.json`. Пользовательский выбор `mine` отделён от `status` выхода серий и `episodes`.
- Источник личных фильмов — `site/data/movies.json`, пользовательский `status` не изменяется автоматически в день релиза.
- `discover.json` — только подборки, рекомендации и даты из источников. Дубликаты при добавлении не создаются.
- На главной дата релиза (при наличии) показывает фильм/сериал из «Хочу» в блоке новинок в день премьеры и 13 дней после. Отметки пользователя остаются нетронутыми.
- Без установленной даты автоматического релиза нет. Ежедневная задача актуализации заполняет подтверждённые даты; кинотеатральная и онлайн-премьера могут различаться.
- Данные `poster`, `rating`, `seen_ep`, `seen_season` не мигрируются и не удаляются.

## Мой сервер (Jellyfin)

- Сервер **не** переносится в `series.json` / `movies.json`.
- Используются прежние настройки `localStorage`: `jf_url`, `jf_token`, `jf_uid`, `jf_dev`. Адрес и токен не попадают в GitHub.
- Вход `data-jfform`, обновление `jfLoad`, каталог `viewJfServer`, выход и настройки `#/settings` сохраняются.
- Если сервер отключён, личные списки, рекомендации и главная продолжают работать.

## Совместимость

Старые ссылки `#/list`, `#/movies`, `#/lib` перенаправляются в соответствующие разделы новой коллекции, `#/cal` возвращает на главную. Страницы `#/s/:id`, `#/m/:id`, `#/settings` сохраняют доступность. Никаких изменений содержимого личных JSON не требуется.

## Перед каждым выпуском

1. Проверить сценарии: обе вкладки; поиск; добавление/удаление; даты непосредственно на постерах; просмотренные; сервер online/offline; вход Jellyfin; уведомления; перенаправления старых ссылок.
2. Синхронно увеличить версию `APP_V` в `cinema.js` и `CACHE` в `sw.js`, проверить список закэшированных файлов.
3. После merge дождаться успешной публикации GitHub Actions и проверить интерфейс в установленной PWA на iPhone.
