# Grach Films v74 — Cinema Noir / автоматическая медиатека

## Принцип

Это **календарь релизов**, не трекер просмотра. В интерфейсе нет статусов «Хочу / Смотрю / Посмотрел», прогресса просмотра, отметок эпизодов и финальных титров. Поля `mine`, `seen_ep`, `seen_ep_season`, `seen_season` сохраняются в старых JSON для совместимости, но не используются и не мигрируются.

## Источник истины

- `site/release-engine.js`: чистая функция `GFReleases.describe(item, today, moscowClock)`; даты и часы — по Москве. Входной `today` — дата YYYY-MM-DD, `moscowClock` — HH:mm (необязательный параметр для тестируемой точности).
- Группы: `new` (последние 13 календарных дней, включая день выхода), `soon` (подтверждённый будущий релиз), `archive` (старый релиз либо нет подтверждённой даты). Эти группы **не записываются в GitHub**.
- Сериал: количество **уже вышедших** эпизодов, общее подтверждённое число, следующая дата и время, завершённость сезона. Финал подтверждается только когда известен полный набор номеров 1..total и все эпизоды вышли.
- Фильм: дата подтверждённой премьеры. Кинотеатральный релиз не гарантирует доступность на конкретном стриминге.
- Неизвестная дата не выдумывается; переносы расписаний учитываются при загрузке новых данных.

## Главная

- «Новые серии» — сериалы с недавними выпусками.
- «Скоро выйдет» — ближайшие подтверждённые серии и премьеры.
- «Премьеры фильмов» — недавние релизы фильмов.
- «Рекомендации» — ниже.
- Через 13 дней после последнего релиза карточка исчезает с главной автоматически; остаётся в «Моё». Даты и число серий показываются прямо на постерах.

## Ручной архив

- Кнопка «Убрать в архив» появляется только после подтверждённого финала сезона либо после даты премьеры фильма.
- `localStorage`: ключ `gf_archive_v1:<s|m>:<id>`, значение — `releaseKey` текущего завершённого релиза. При новом сезоне/новом релизном событии старый ключ перестаёт действовать.
- Кнопка необязательна: автоархив работает и без неё. Обратное действие — «Вернуть из архива». Никаких коммитов при нажатии.
- На другом устройстве ручная отметка не синхронизируется. Jellyfin и настройки токена независимы.

## Личный список «Смотрю сейчас» (v74.4)

- На **главной**, над «Новыми сериями», находится единственный раздел «Смотрю сейчас», который объединяет сериалы и фильмы и показывается только при наличии личных отметок.
- На странице сериала доступна кнопка «▶ Смотрю сейчас» / «✓ Закончил смотреть»; на странице **фильма** — после подтверждённой даты его премьеры. Кнопка не меняет данные GitHub.
- Личный статус на этом устройстве хранится в `localStorage`: ключи `gf_watching_v1:s:<id>` (сериалы — совместимость с v74.3) и `gf_watching_v1:m:<id>` (фильмы), значение `1`.
- Отмеченный релиз показывается на главной в «Смотрю сейчас» даже если его сезон завершён и он ушёл в архив. В остальных разделах **главной** такая карточка не дублируется. В «Моё» сериал или фильм по-прежнему остаётся в обычном разделе «Актуальное» или «Архив» без отдельного блока «Смотрю сейчас».
- Снятие отметки немедленно удаляет карточку из личного блока главной. Обычная сортировка по датам/архиву продолжает действовать и не изменяется.
- Статус просмотра независим от `mine`, `seen_ep`, `seen_season`, автоматического 13-дневного архива и ручных архивных отметок. На другом устройстве локальная отметка не синхронизируется.

## Навигация и совместимость

- Две вкладки: `#/week` (Главная) и `#/mine` (Сериалы / Фильмы / Мой сервер).
- Случайный подбор — кубик в шапке; поиск — из «Моё».
- `#/list`, `#/posters` → `#/mine/series`; `#/movies` → `#/mine/movies`; `#/lib` → `#/mine/server`; `#/cal` → `#/week`.
- Jellyfin (`jf_url`, `jf_token`, `jf_uid`, `jf_dev`), кнопка «Смотреть», GitHub-токен, подписки и push сохраняются. `notify.mjs` не фильтрует фильмы по устаревшему `watched`.
- После добавления название сохраняется без статуса просмотра; расписание дополняется внешней автоматизацией. Существующие JSON не переписываются миграцией.

## Проверки и выпуск

- `cd series-app && npm install && npm run test:syntax && npm test` — Node unit-тесты движка + jsdom smoke-тесты маршрутов, локального архива, Jellyfin и старых ссылок.
- Изменения `APP_V` и `CACHE` повышать одновременно, обновлять список `SHELL` в service worker.
- После ревью PR проверить на реальном iPhone PWA, загрузку расписаний, GitHub Actions и приватный Jellyfin.
- Плановые задачи обновления дат, которые раньше ориентировались на `mine='want'`, перенастроить **после принятия PR**, чтобы они проверяли всю коллекцию без статусов. Не менять их заранее на рабочем `main`.
