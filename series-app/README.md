# Сериалы

Приложение, которое показывает, когда выходят новые серии и сезоны, и присылает уведомление в день выхода.

- `site/` — само приложение (страница для телефона, добавляется на экран «Домой»).
- `site/data/series.json` — список сериалов и расписание. Здесь меняются даты.
- `scripts/notify.mjs` — отправляет push-уведомления о сериалах, которые выходят сегодня.
- `.github/workflows/series-app.yml` — публикует сайт и каждый день в 10:00 по Москве запускает отправку.

## Подключение (один раз)

1. **Страница.** GitHub → Settings → Pages → Source: **GitHub Actions**. После первого запуска workflow приложение откроется по адресу `https://<логин>.github.io/<репозиторий>/`, точный адрес виден в шаге deploy.
2. **Ключ уведомлений.** Settings → Secrets and variables → Actions → New repository secret: `VAPID_PRIVATE_KEY` (значение из файла с ключом).
3. **Телефон.** Откройте адрес в Safari, «Поделиться» → «На экран Домой», запустите приложение с иконки, вкладка «Уведомления» → «Включить уведомления».
4. **Код устройства.** Скопируйте его в приложении и добавьте секретом `PUSH_SUBSCRIPTION`. Для второго телефона секрет делается массивом: `[код1, код2]`.
5. **Проверка.** Actions → «Сериалы» → Run workflow → галочка «Отправить тестовое уведомление».

## Как добавить сериал из приложения

В списке нажмите «+ Добавить». Один раз вставьте токен GitHub (fine-grained, только этот репозиторий, право Contents: Read and write): он хранится только в браузере телефона. Сериал попадёт в `series.json` со статусом `nodate`, поле `added` показывает дату добавления.

## Как менять расписание

Правьте `site/data/series.json`: у каждого сериала есть статус (`airing`, `waiting`, `nodate`, `ended`), а у выходящих — список серий с датами. После коммита сайт обновится сам.

## Ограничения

- GitHub отключает расписание в публичных репозиториях без активности 60 дней. Любой коммит его возвращает.
- Запуск по расписанию может сдвигаться на несколько минут.
- Уведомления на iPhone работают только из приложения, добавленного на экран «Домой» (iOS 16.4 и новее).
